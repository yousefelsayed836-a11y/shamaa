# شامآ | SHAMAA LUXURY ABAYAS

صفحة عربية متجاوبة لروابط شامآ، بتصميم أخضر وذهبي.

تحتوي على زر «اعرفي مفاجأتك» لإظهار كود SHAMAA10 ونسخه، ورابط أحدث العبايات على كتالوج واتساب، وروابط إنستجرام وتيك توك وفيسبوك.

## المعاينة

افتح `index.html` في المتصفح، مع إبقاء `brand-reference.png` بجواره.

## GitHub Pages

الموقع ثابت ولا يحتاج إلى تثبيت أو بناء. يمكن نشره من جذر المستودع على فرع `main` باستخدام GitHub Pages.
